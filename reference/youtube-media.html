YouTube 媒体速查表

添加、替换视频时，先修改内容，再通过 HTTP 本地预览检查。

最小可用对象

{
  "src": "https://youtu.be/你的视频ID",
  "alt": "这段视频展示什么",
  "caption": "可选的下方说明"
}
字段作用
src视频来源。替换视频时修改它。
alt内容说明，映射为 iframe 的 title。
caption视频下方图注，可省略。

放在哪里

位置填写位置
总览后的大段演示visualBreakMedia 数组
某个叙事段落中的演示story.sections 对应节的 media 数组
主媒体或图库detailMedia 数组
封面兼主播放器coverMedia；首页自动使用缩略图

媒体的 src 是播放来源；项目的 link 是卡片跳转地址。把 YouTube URL 写进 link 不会创建内嵌播放器。

链接与术语

支持观看链接、youtu.be 分享链接、embed 链接，以及 shorts、live 链接。有效起播时间 t=90、t=1m30s 或 start=90 会保留，其他参数不直接传给播放器。

视频 ID：标识视频的那一段字符。嵌入地址：带 /embed/ 的播放器地址。iframe：在当前网页里呈现另一个网页的 HTML 元素。MDN 定义

播放不成功时

确认视频允许站外嵌入、网络能访问 YouTube，并通过 HTTP 服务器打开页面。不要把 YouTube 网页 URL 当作 <video src> 的视频文件。官方排查说明
