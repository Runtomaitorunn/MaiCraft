## Anti-Patterns Verdict

**LLM assessment:** 视觉不显得模板化，Cold Paper 配色、真实项目封面和排版保留了作品集个性。问题在行为层：播放器外观包装了工程回退方案，dialog 没有独立任务，只是多加一步。

**Deterministic scan:** `detect.mjs --json index.html` 返回 3 个 warning：`overused-font`（index.html:13）、`broken-image`（index.html:99）、`single-font`（index.html:13）。前者属于既有品牌字体选择；后两者是静态扫描误报，poster 在打开前由 JS 注入，CSS 实际使用 display/body 两套字体。检测器没有覆盖“伪播放器外跳”这一行为语义。

**Visual overlays:** 浏览器检测代理报告 `No browser is available`，因此没有注入 overlay。此前已保存的桌面/手机截图和源码足以确认布局，但没有本轮新增 overlay。

## Overall Impression

视觉修复成功，UX 修复不完整。访客点击播放时的预期是“在这个 dialog 里播放”，实际结果是被交给 YouTube。作品集最重要的奖励时刻因此变成平台交接，削弱信任和连续浏览。

## What's Working

- 本地 poster 让两个项目不再以黑屏开场。
- dialog 在桌面和手机上尺寸稳定，层级清楚，关闭目标足够大。
- `View project` 保留了继续了解项目背景的路径。

## Priority Issues

### [P1] 播放 affordance 违背行为承诺

**Why it matters:** 圆形播放按钮、全幅可点击海报和 “Watch video” 都表示原位播放；外跳会让界面显得不可信。

**Fix:** 最佳方案是在 dialog 内播放自托管 MP4/WebM，并把 “Watch on YouTube ↗” 作为次级回退。如果不能可靠内播，就去掉伪播放器造型，明确写 “Watch on YouTube ↗”；如果 dialog 只负责外跳，直接移除 dialog。

**Suggested command:** `/impeccable shape video viewing flow`

### [P1] Dialog 是没有决策价值的死步骤

**Why it matters:** 卡片打开 modal，modal 再打开 YouTube；放大的 poster 没有增加时长、角色、成果或技术证明。

**Fix:** 要么让 dialog 真正播放，要么把它升级为有价值的 preview sheet，包含一句项目价值、角色/成果和两个明确目的地。否则卡片直接链接更诚实。

**Suggested command:** `/impeccable distill video dialog`

### [P2] 外跳返回后留下过期 modal 状态

**Why it matters:** 访客返回作品集后还要再关闭一次 dialog，移动端 app handoff 时更容易失去位置感。

**Fix:** 如果保留外链，激活外链时先关闭 dialog，保留滚动位置，并把焦点还给来源卡片。

**Suggested command:** `/impeccable harden video dialog`

### [P2] 核心作品证明完全依赖外部平台

**Why it matters:** 地区、公司网络、登录挑战、广告或慢连接都可能在高兴趣时刻造成死路。

**Fix:** 在站内提供 20–40 秒自托管短片、轻量动图或关键帧/文字回退，YouTube 只承担完整版。

**Suggested command:** `/impeccable optimize project media`

## Persona Red Flags

**Jordan，第一次访问:** 把 “Watch video” 理解为当前 frame 播放；无法预测外跳，也不知道 `View project` 会去 Wix、Devpost 还是站内页面。

**Riley，压力测试:** 会发现 `aria-haspopup=dialog`、播放器外观和外链行为不一致；YouTube 被阻断时没有恢复路径；返回后 modal 仍拦截原页面。

**Casey，移动访问:** 多一次点击，可能触发 YouTube app handoff，返回成本更高；顶部关闭按钮成为额外清理步骤。

**招聘方/合作方:** 快速比较项目时不断生成 modal 与外部标签；最强作品证据脱离角色、奖项和技术上下文，容易被 YouTube 推荐流截走。

## Minor Observations

- 初始焦点落在 “Close video”，键盘/读屏用户先遇到退出而不是主动作。
- 当前没有视频播放，“Close video” 应改成 “Close preview”。
- `Watch video` 和 `View project` 都是外链，但都没有外链标识。
- Habibi poster 主要是黑底 monogram，放大后没有增加项目证明。

## Questions to Consider

- 如果 dialog 不播放，它的独特任务是什么？
- “一键看到创意证明”是否应该成为这个作品集的硬标准？
- 20–40 秒站内短片能否先完成说服，再把完整版交给 YouTube？
