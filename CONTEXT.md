# Ye Mai Portfolio

This context describes the language used to author and render Ye Mai's portfolio content. It exists so project storytelling, reusable templates, and renderer behaviour use the same terms.

## Language

**Project Authoring**:
The act of writing portfolio project content in a stable shape before it is rendered on the homepage or detail page.
_Avoid_: page config, renderer data, raw JSON

**Case Study**:
A project story that explains context, strategy, implementation evidence, and outcome for a selected work.
_Avoid_: project page, portfolio item

**Story Section**:
A repeatable section inside a case study, combining a narrative role with a layout shape.
_Avoid_: block, content component, row

**Evidence Stack**:
A story section layout that presents outcome text, a main evidence image or video, a short observation, and supporting media.
_Avoid_: impact gallery, outcome media block
